# features/scoring

**Purpose:** Cross-feature scoring engine — used by `features/survey/` (after-submit) and `features/report/` (display). V4+V5 dual-path engine over 14 archetypes, 21 dimensions, 25 overlays.

**Entry:**

- `logic/index.ts` — public barrel (`@features/scoring/logic`).
- `logic/engine.ts` — V4 softmax + V5 anchor-calibrated scoring.
- `logic/config.ts` — config loader (reads `data/scoring-config.ts`).
- `logic/types.ts` — shared types.
- `tests/` — engine, config, V5, verification tests.

**Belongs:** scoring math, gate evaluation, weight modifiers, archetype calibration, prototype helpers.

**Does NOT belong:**

- Generated config (`data/scoring-config.ts` stays in `data/` — regenerated by `scripts/update-scoring-config.js` from source CSVs).
- Survey-question runtime (use `features/survey/`).
- Admin scoring dashboards (use `features/admin/server/`).

**Engine version:** `v4+v5` (kept stable across V7→V8→V9 config refreshes; bumping breaks admin dashboards that query `engine_version=v4+v5`).
