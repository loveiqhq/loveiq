# Command Center and Shell

Use this domain for the `/admin` landing experience, leadership views, shell navigation, and cross-surface operating controls.

## What belongs here

- Shell layout, sidebar, header, and command palette
- The command-center snapshot and leadership dashboards
- Goals, org-level views, tags, changelog, tools, and shell-wide state

## What does not belong here

- Submission review workflows: use [`submissions.md`](submissions.md)
- Pure analytics dashboards like funnels or scoring: use [`growth.md`](growth.md) or [`scoring.md`](scoring.md)
- Health diagnostics and incident views: use [`health.md`](health.md)
